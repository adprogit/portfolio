## En bref

Ce site ne dépose **aucun cookie**, n'utilise **aucun outil de mesure
d'audience** et ne charge **aucune ressource tierce** (polices, vidéos,
scripts). Il ne contient aucun formulaire.

## Ce qui est stocké sur votre appareil

- `theme` (stockage local du navigateur) : votre choix de thème clair ou
  sombre, enregistré uniquement si vous cliquez sur le bouton de thème. Il ne
  quitte jamais votre navigateur. Vous pouvez l'effacer via les réglages de
  votre navigateur. Préférence d'interface demandée par vous : exemptée de
  consentement.

## Fichiers que vous chargez

Le lecteur de parties d'échecs (PGN) lit le fichier que vous choisissez
**dans votre navigateur**. Il n'est ni envoyé ni conservé.

## Journaux de l'hébergeur

Le site est hébergé par GitHub Pages (GitHub, Inc.). Comme tout serveur web,
GitHub enregistre techniquement l'adresse IP des visiteurs pour la sécurité et
le bon fonctionnement du service. L'éditeur du site n'a pas accès à ces
journaux. Voir la déclaration de confidentialité de GitHub :
https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement

## Liens externes

Les liens vers GitHub et LinkedIn ouvrent ces sites, soumis à leurs propres
politiques. Aucune information de provenance (« referrer ») n'est transmise.
